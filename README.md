# Zain – Progress with Purpose

An immersive cinematic scroll-driven storytelling experience showcasing Zain's evolution from a telecommunications company into a modern technology ecosystem.

## Tech Stack
- **Framework**: Next.js 15 (App Router), React 19
- **Language**: TypeScript (strict mode)
- **Styling**: TailwindCSS, clsx, tailwind-merge, cva
- **3D Engine**: Three.js, React Three Fiber, @react-three/drei
- **Animation**: GSAP, Framer Motion
- **Scroll Handling**: Lenis
- **State Management**: Zustand

## Quick Start

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm dev
```
